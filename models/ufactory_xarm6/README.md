# UFACTORY xArm6 with the xArm gripper (MJCF)

The xArm6 for the TidyBot simulation, with the UFACTORY xArm gripper.

| File | Contents |
|---|---|
| `xarm6.xml` | the arm with the gripper and a wrist camera, on a 12 cm riser |
| `xarm6_nohand.xml` | the arm alone (`pinch_site` on the flange), used by `ik_solver.py` |
| `scene.xml` | `xarm6.xml` with a floor and a cube |
| `../stanford_tidybot/tidybot_xarm6.xml` | the TidyBot base with the arm on its arm plate |
| `../stanford_tidybot/scene_xarm6.xml` | the base with the arm, a floor and a cube (`MujocoEnv(arm='xarm6')`) |

All of them are generated by `build_models.py` from one description of the arm. Edit
that script, not the XML, then run:

```bash
python models/ufactory_xarm6/build_models.py
```

## Sources

- **Arm**: UFACTORY's [xarm_ros2](https://github.com/xArm-Developer/xarm_ros2) `xarm_description`:
  - joint origins come from `xarm6_default_kinematics.yaml`;
  - link inertials come from `xarm6_type6_HT_BR2.yaml`, the default;
  - meshes come from `meshes/xarm6/visual`;
  - joint ranges are the controller's: J1/J4/J6 ±360°, J2 −118°..120°, J3 −225°..11°, J5 −97°..180°;
  - actuator force limits are the rated joint torques (163.2 / 81.6 / 30.6 N·m).
- **Gripper**: [MuJoCo Menagerie](https://github.com/google-deepmind/mujoco_menagerie)'s `ufactory_xarm7`. The bodies, the linkage constraints, the actuator (`ctrl` 0 open .. 255 closed) and the meshes are used unchanged; only the class names are prefixed.

## Checks

- With every joint at zero, the flange is at (0.207, 0, 0.112) m, pointing down. This matches the xArm6 manual's zero pose.
- The IK model plus the 0.172 m TCP offset reproduces `pinch_site` of the full model exactly, in both position and orientation.
- The retract and home poses (`build_models.py`: `RETRACT`, `HOME`) were solved with the IK and checked for contacts with the base.
- Driven like `main.py` drives the sim, the arm on the base picks up the cube: 5 of 5 seeds.

## Assumptions to check against the real robot

- The arm sits where the Kinova sat: the arm plate's top, 0.335 m up, on the base's centre (`MOUNT_POS`).
- The wrist camera is placed beside the gripper, aimed at the TCP 23° off the tool axis (640×360, 60° fov). Match it to the real camera's mount.
