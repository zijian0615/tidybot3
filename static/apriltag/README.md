# Safari AprilTag teleoperation assets

The detector files in this directory come from `AliAlimohamad/apriltag-js`
and are distributed under the BSD-2-Clause license in
`LICENSE.apriltag-js`. The detector is an Emscripten build of
`AprilRobotics/apriltag`.

The teleoperation page uses the `tag36h11` family, tag ID 0. The configured
tag size is the physical width of the outer black square (the detector's four
corners), not the surrounding white margin.
